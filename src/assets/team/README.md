# Fotos del Equipo

Coloca aquí las fotos de cada integrante del equipo.

## Instrucciones:
1. Agrega la foto con el nombre del integrante, ej: `alex-ramirez.jpg`
2. Abre `src/data/index.js`
3. Busca el integrante y actualiza el campo `photo`:
   ```js
   photo: "/src/assets/team/alex-ramirez.jpg"
   ```
4. La foto aparecerá automáticamente en la página del equipo.

## Formatos soportados: .jpg, .jpeg, .png, .webp
## Tamaño recomendado: 400x400px (cuadrada)
